## 🚀 Featured projects

| Project | What it is | Built with |
|---|---|---|
| 🛵 **[LannPya AI](https://github.com/FightaHackathon/Lan_Pya_AI)** | Turns messy Messenger/Viber delivery orders written in casual Burmese into structured, triaged deliveries. Rules first, Gemini only where rules stop, with Zawgyi detection, a 33-township dictionary, privacy redaction and a secure buyer tracking link. 141 tests. | TypeScript · Gemini · Zod · Vitest |
| 🌍 **[SeismicLogic](https://github.com/FightaHackathon/Seismilogic)** | 3D earthquake simulator comparing a fixed-base Mandalay brick building with a base-isolated Japanese steel structure, with P/S waves, stress colouring and a live seismograph. | Three.js · Rapier physics |
| 🖥️ **[UIT Hardware Specialist](https://github.com/FightaHackathon/UIT_Hardware_Specialist)** | Expert system that checks PC builds and laptops against UIT coursework (Android Studio, Unity, Docker, ML). Compatibility rules plus LLM explanations, in English and Burmese. | React · TypeScript · Express · Mistral AI |
| 🎮 **[GamePulse](https://github.com/FightaHackathon/gamepulse-showcase)** | Game analytics web app with Player, Streamer and Developer views. Reads a public Steam profile and recommends games using review, activity and momentum signals. | Next.js · FastAPI · Postgres · Recharts |
| ⚡ **[SMR Nexus](https://github.com/FightaHackathon/Nuclear_dashboard-and-prototype-website-for-Yangon)** | Proposal site and dashboard for Small Modular Reactors as 24/7 backup power for Yangon's homes and industrial zones. | React · TypeScript · Python |
| 🪐 **[Aetherbound](https://github.com/FightaHackathon/aetherbound)** | Sky-voyage strategy game where you cross five islands with three AI crewmates who decide using expected utility, plus a 500-run evaluation mode. | Python · Pygame |
| 🔬 **[Image FFT Analyzer](https://github.com/FightaHackathon/Image_FFT_Analyzer)** | Uses Fourier transforms to tell AI-generated images from natural photos, with a small CNN trained on the frequency features. | Python · Streamlit · CNN |
| 📚 **[Edu-AI](https://github.com/FightaHackathon/Edu-Ai)** | Study assistant with three modes: chat with a PDF (RAG), ask questions about a web page, and run a quick web research agent. | Python · LangGraph · Hugging Face · Selenium |
| 💆 **[Insight Care](https://github.com/FightaHackathon/Insight-Care)** | Skincare consultation site with skin, colour, body shape and hair analysis plus clinic booking. | HTML/CSS/TS · Spring Boot |
